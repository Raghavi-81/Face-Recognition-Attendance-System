# Face Recognition Attendance System

A Python-based Face Recognition Attendance System developed using OpenCV and SQLite. The system uses a webcam to detect and recognize registered faces and automatically records attendance.

## Features

- Face registration using webcam
- Face detection using Haar Cascade
- Face recognition using LBPH
- Automatic attendance recording
- SQLite database for storing attendance
- Prevents duplicate attendance for the same day
- Displays today's attendance records

## Technologies Used

- Python
- OpenCV
- OpenCV-Contrib
- NumPy
- SQLite
- Jupyter Notebook
